# テストシナリオ

- 実施日：2026-10-18（チーム全員）／最終確認：2026-10-28
- 環境：ローカルと本番の両方
- 端末：iPhone 15・16 は実機。iPhone SE・Galaxy は PC のエミュレーション（画面幅と見た目のみ）
- 結果：○＝期待結果と一致
- 設計は [`テスト設計書`](./テスト設計書.md)

## シナリオ1：生徒フロー

| ID | 手順 | 期待結果 | 結果 |
| -- | ---- | -------- | ---- |
| S-01 | 学校コードとニックネームを入力して「はじめる」 | 送信中は「はじめています…」で無効化。成功でカード選択へ | ○ |
| S-02 | カードを1個選ぶ | 「選択中 1/3」、枠とチェックで選択状態が分かる。「次へ」が有効 | ○ |
| S-03 | 3個選んだ状態で4個目をタップ | 増えず「3つまで選べます」が出る | ○ |
| S-04 | 選択0個の状態 | 「次へ」が無効 | ○ |
| S-05 | 自分らしさチェック1〜5問に回答 | 選択だけでは進まず「次へ」で遷移。未選択は無効。5問目は「結果を見る →」 | ○ |
| S-06 | 3問目で「戻る」 | 前の回答が保持され変更できる。1問目の「戻る」はカード選択へ | ○ |
| S-07 | 「結果を見る」を押す | 「自分らしさを見つけています…」のあと、強みカード3つ。順位は付かない | ○ |
| S-08 | 強みカードの「ヒントを見る」 | 最初は全部閉じ、押したカードだけ開く | ○ |
| S-09 | 結果の文言を確認 | 「〜がありそう」「〜かも」。「向いている」「理系/文系」「すべき」が無い | ○ |
| S-10 | 「仕事を見てみる」で職業一覧へ | 「探しています…」のあと10件。上スワイプとボタンの両方で次へ | ○ |
| S-11 | 職業詳細を開く | 4ブロック。文理ラベルは学問側だけ | ○ |
| S-12 | 「職業一覧に戻る」 | 一覧の直前の位置に戻る | ○ |
| S-13 | 「もう一度やり直す」 | カード選択に戻り再診断できる | ○ |
| S-14 | 「おわる」を押す | セッション終了で入口へ。戻るで再入場できない | ○ |
| S-15 | タブを閉じて再度開く | セッションは終了し入口から始まる | ○ |
| S-16 | 同じ入力で2回診断 | 強みの説明が同じ（キャッシュ）。職業順も同じ | ○ |
