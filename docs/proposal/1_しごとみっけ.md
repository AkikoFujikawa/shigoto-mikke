# しごとみっけ

## 企画概要

高校1〜2年生（文理選択前）を想定ペルソナに、「好きなこと・興味・得意・価値観」を入力してもらい、AIが内容を整理する。

整理した内容をもとに、あらかじめデータベースに登録した職業の中から、本人の興味と関連する職業を複数提案するWebアプリ。

気になった職業について、仕事内容だけでなく、関連する文系・理系とのつながりまで確認できるようにする。AIが「この職業に向いている」「理系にするべき」と決めるのではなく、知らなかった職業との出会いを作り、文理選択や今後の進路を自分で考える材料を増やすことを目的とする。

学校経由で生徒に提供することを想定し、無料体験後に学校単位で導入するモデルを検討する。

## 背景・社会課題

- 高校生は文理選択や進学など、早い段階から将来について考える必要がある.一方で、世の中にどんな職業があるのかを幅広く知る機会が少ない
- 高校卒業者への調査では、高校時代に実施してほしかった活動として「インターンシップ」44.3％、「職場見学」37.3％が挙げられており、職業や働くことについて知る機会へのニーズがみられる
- 国立教育政策研究所の調査では、高校生の20.5％が「将来就きたい職業や仕事がまだ決まっていない」と回答している。
- 職業名自体を知らないと検索することも難しく、自分や家族が知っている職業の中から進路を考えやすい
- 厚生労働省「令和5年若年者雇用実態調査」では、初めて勤務した会社を辞めた若者の21.7％が、離職理由として「仕事が自分に合わない」を挙げている
- また、若年正社員の31.2％が転職を希望しており、そのうち41.9％が「仕事が自分に合った会社にかわりたい」と回答している
- 高校生のうちから多様な職業を知り、自分の興味や価値観と仕事について考える機会を増やすことで、より納得感のある進路・職業選択につなげ、将来的なミスマッチを減らす一助になることを目指す

## ペルソナ

- 仮名：美咲さん
- 学年：高校1年生（2年生で文理選択がある私立共学校／長野県・地方）
- 部活：高校1年生の夏にソフトテニス部へ入部し、部活動に邁進中
- 家族構成：父（会社員）、母（パート）、弟（中学1年生）
- 趣味：推し活
- きっかけ：夏休みの課題として「文理選択をする前に、自分の興味関心のあるお仕事を調べてみる」宿題が出た

## 状況

受験を頑張ったものの、第二志望の学校に入学することになった。挫折した経験もあり、今後の目標を持って入学してきたが、どんな大学があるのか、どんな職業があるのかイメージがつかない。

部活も忙しくなってきており、将来の目標がなんとなく見えないまま時間が過ぎていきそうな状態。本人も親も「これで良いのか」と自問自答している。親もどうアドバイスすればよいか分からず、悶々としている。

本人・親ともに「知っている職業」の範囲でしか会話ができず、視野が広がらない。なんとか手助けが欲しいと思っていたところに、学校から「しごとみっけ」アプリが提供された。

## 解決したい課題

### 生徒（美咲さん）
- 知っている職業の範囲でしか進路を考えられず、視野が広がらない
- 興味のある職業を見つけても、その職業がどのような学問・学部や文理選択につながるのか分からず、次の行動につなげにくい

### 親
- 子どもと同じく、知っている職業の範囲でしか会話ができない
- 偏った知識・価値観の中でしかアドバイスできず、子どもの視野を広げる手助けができない

### 学校
- 生徒一人ひとりの興味・関心に合わせた進路選択支援の手段が不足している
- 進学実績を上げたいが、生徒個々の進路選択を後押しする有効な手段を持てていない
- 少子化により生徒数が減少傾向にある中、学校の魅力・実績を高め、入学希望者の減少に歯止めをかけたいという課題も抱えている

## 理想状態

- **生徒（美咲さん）**：自分の好きなこと・興味・価値観を整理し、これまで知らなかった職業を知る。さらに、気になった職業と学問・学部・文理とのつながりを理解し、文理選択や今後の進路を自分で考える材料を得られる。
- **親**：偏った価値観に頼らず、子ども個々に合ったアドバイスができるようになり、視野を広げてあげられる
- **学校**：生徒一人ひとりの興味・関心に応じた進路探索を支援できる。生徒が職業と学問・文理とのつながりを理解し、進路について考えるきっかけを提供できる

## 今後の展望

MVPでは、職業の文理とのつながりまでを提示する。
今後は、大学ポートレート等の外部データとの連携を検討し、関連する学問や学部、実際の大学・学部・学科情報まで探索できるように拡張する。
興味・価値観 → 職業 → 学問・学部 → 実際の進学先候補
まで一貫して探索できるサービスを目指す。

## 導入・収益モデル

- 夏休み期間に1ヶ月無料で生徒が実際に試し、良ければ学校が導入を決定する流れ
- 導入後は学校が一括で費用を負担
- 料金イメージ（学年一括契約の例）：1学年200人規模の高校で年間10万〜30万円程度（1人あたり500〜1,500円換算）

## 企画レビューで確認したいこと

- 「職業を知る」だけでなく、職業→関連する学問・学部→文理とのつながりまで提示することで、文理選択を考える材料を提供するというゴール設定は適切か

- AIで生徒の興味・価値観を整理し、登録済みの職業DBから関連する職業を提案するというSolutionで、課題を解決できているか

- 4週間のMVPとして、職業数を絞って一連の体験を完成させるスコープは適切か
